# Examples

Working examples. The tests in `tests/` load them and compare the results.

| File | Shows |
|---|---|
| `config/base.psd1` | references, built-ins, `env:`, filters, escape, `!if` |
| `config/next.psd1` | merge grammar |
| `config/last.psd1` | `!merge` with certain keys, `!include`, globs, namespaces, `this::` |
| `config/extra.psd1` | file merged for one key only |
| `config/shared.psd1` | included file |
| `config/conf.d/metrics.psd1` | found by a glob, with `!name` |
| `config/app.schema.psd1` | schema |
| `config/Types.psm1` | your own enums, used as schema types |
| `schema-keywords.psd1` | every schema keyword in one small file |
| `config/result.psd1` | what importing `last.psd1` returns. Written by hand, checked by the tests |
| `typed/App.Types.psm1` | generated by `New-PsdType` |
| `typed/app.config.ps1` | a config script using those types |
| `everything/` | one config using every feature, import `app.psd1`, the answer is in `result.psd1` |
| `usage.ps1` | every command |
| `errors.txt` | real error output for common mistakes |

Every `.psd1` here loads with plain `Import-PowerShellDataFile`, and the types work on 5.1 and 7.
